# МТС Energytool — ИИ-консультант

Репозиторий команды для кейса МТС: консультация по выданной базе знаний, уточнение ситуации клиента и формирование заявки менеджеру.

В этой ветке можно проверить один сценарий консультации в веб-чате и через CSV. [Как запустить демо](docs/CONSULTATION_SLICE.md).

## Быстрый запуск

Из корня репозитория выполните `docker compose up --build` и откройте [локальный чат](http://127.0.0.1:8080/). По умолчанию работает синтетический сценарий с SQLite. Для запуска с выданной базой и прокси организаторов см. [Docker и настройки](docs/I4_DOCKER.md).

## Проверить I1 без прокси

Нужен Python 3.11+. Из корня репозитория:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m examples.i1_offline
```

Настоящие ключи и `.env` для этих команд не нужны. Тесты используют синтетические данные и локальный HTTP-сервер. Доступность и качество настоящих моделей пока не проверены.

Закрытую базу знаний, её копии/индексы, API-ключи и реальные персональные данные не коммитим. Для примеров используем синтетические данные. Перед реализацией проверяем актуальный регламент организаторов.

По Q&A готовый индекс допускается в корне сабмита. Письменный регламент пока противоречит этому ответу: план предусматривает проверку переноса файлов платформой и резервное построение при старте. Подробности и временные отметки — в документе уточнений.
