# МТС Energytool — ИИ-консультант

Репозиторий команды для кейса МТС: консультация по выданной базе знаний, уточнение ситуации клиента и формирование заявки менеджеру.

**Опубликован backend-блок (S1–S4 и автоматическая часть S5) на синтетическом engine. Консультант, поиск, web и упаковка — в работе у остальных участников.**

```bash
pip install -r requirements-backend.txt
pytest                                   # контракты, сессии, заявки, debug, e2e
uvicorn backend.app:app --port 8000      # API: http://localhost:8000/docs
```

По 5 задач и 12 условных баллов сложности каждому: Влад — данные/RAG; Максим — консультант/качество; Алексей — API/платформа/Docker; Женя — backend/сессии/заявки; Катрина — веб-интерфейс.

Закрытую базу знаний, её копии/индексы, API-ключи и реальные персональные данные не коммитим. Для примеров используем синтетические данные. Перед реализацией проверяем актуальный регламент организаторов.

По Q&A готовый индекс допускается в корне сабмита. Письменный регламент пока противоречит этому ответу: план предусматривает проверку переноса файлов платформой и резервное построение при старте. Подробности и временные отметки — в документе уточнений.
