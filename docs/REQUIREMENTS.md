## Платформенный контракт

По изученному регламенту: DATA_DIR/questions.csv (id,question), выданный knowledge-base.zip; результат submission.csv в рабочем каталоге, только id,answer, по одному непустому ответу на ID. История в демонстрационных вопросах многострочная, внутри CSV. Максимум ответа 10 000 символов; обычно до 150 слов. ZIP содержит только корневые .py и закреплённый requirements.txt; без данных/индексов/конфигов/whl и pip install в runtime. Записанные лимиты: 128 МБ, 8 CPU, 16 ГБ RAM, 20 минут, 5 отправок в сутки. До реализации сверить актуальный регламент.

## Допуск и оценка

Допуск требует одновременно положительного результата LLM-судьи, рабочего web-пути до заявки и полного комплекта сдачи. Онлайн: 50% автоматическая оценка и 50% экспертная. Автооценка: 70% Match Rate + 30% Win Rate, сравнение с baseline в двух порядках; public и private наборы различаются. Экспертные веса: работоспособность 30%, консультация 25%, скорость/стабильность 15%, архитектура 15%, безопасность/документация 10%, презентация 5%. Финал: результат онлайн-этапа 40%, защита 60%.

## Финальная проверка команды

- [ ] Действующий технический регламент и спорный пункт индекса уточнены.
- [ ] Есть действительный положительный результат допустимого сабмита; демо-тесты не названы private golden.
- [ ] На чистом окружении воспроизводится Docker-запуск и web-путь до заявки.
- [ ] Истории без заявки сохраняются; новый контекст изолирован.
- [ ] Ошибки API/БД/повторы не теряют и не смешивают данные.
- [ ] Источники и ограничения проверяемы; нет выдуманных коммерческих обещаний.
- [ ] Репозиторий/ZIP/PDF совпадают с проверенным SHA; участники проверили локальные непопавшие коммиты.
- [ ] В PDF первый слайд содержит порядок проверки, repo и при наличии ссылку на UI.
- [ ] Жюри имеет доступ; действующие секреты и закрытая БЗ не опубликованы.

Источники требований: выданный PDF кейса, технический регламент и папка материалов организаторов. В этот repo исходные материалы не загружались.
