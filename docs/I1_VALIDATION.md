# Проверка I1 без доступа к прокси

Дата: 11 ноября 2026. Среда: macOS arm64, Python 3.12.14, `httpx==0.28.1`. Набор запускается из корня репозитория. Другие версии Python пока отдельно не прогонялись; код требует Python 3.11+.

## Выполнено

| Проверка | Результат |
|---|---|
| `python -m unittest discover -s tests -v` | 50 тестов, OK |
| `python -m compileall -q organizer_api.py tests examples` | OK |
| `python -m examples.i1_offline` | Три синтетических ответа, `real_proxy_checked: false` |
| `python -m examples.i1_live_check` без флага | Запросы не отправлены |
| Будущая live-команда с `--live` против локального фиктивного сервера | Три HTTP-маршрута прошли; это часть тестов, не обращение к организаторам |
| Live-команда с отсутствующим окружением | Выход 2, безопасная ошибка конфигурации до сетевого запроса |

В 50 тестов входят 6 проверок настоящего TCP/HTTP на `127.0.0.1`, 3 проверки команд и 41 проверка конфигурации/клиента. Внутри отдельных тестов есть дополнительные варианты входов и ошибок; они не подсчитаны как отдельные тесты в итоговых 50.

Проверены:

- Алиасы и приоритет окружения, отсутствие зашитой генеративной модели, пустые значения/самоссылки, неверные числа и адреса.
- Три маршрута, UTF-8, раздельные ключи с fallback на общий, передача дополнительных параметров без перезаписи обязательных полей.
- Порядок эмбеддингов, конечные числа, размерности, дубли/пропуски индексов и формат реранкера, включая ответы только с индексами.
- 401 без повтора; 408/429/5xx, сетевые ошибки и таймауты с конечными попытками; отсутствие перехода по редиректу.
- Очередь и ограниченный параллелизм, общий срок, медленная выдача частями, `Retry-After`, отмена и освобождение слота.
- Пустой/оборванный/невалидный ответ, предел размера, отсутствие выдуманного fallback-ответа.
- Отсутствие синтетического ключа и текста клиента в диагностике/traceback, конфигурационном repr и метриках.

Все ответы, ключи и тексты — синтетические. Организаторская БЗ и настоящие ключи не использовались. Содержание ответов фикстур не является продуктовым обещанием.

## Не выполнено

Настоящий прокси недоступен: его маршруты, модели, thinking/reasoning, фактические размерности, ограничения, задержки и платформенный запуск ещё не проверены. Остаток приёмки описан в [инструкции клиента](I1_API_CLIENT.md#что-ещё-нельзя-подтвердить-без-доступа). Задачу I1 нельзя считать полностью проверенной на сервисе по одному успешному локальному набору.
