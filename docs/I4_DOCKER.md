# Docker-запуск и CI

Нужны Docker Engine или Docker Desktop и Docker Compose 2.24+. Образ использует Python 3.12 и запускает приложение от непривилегированного пользователя. Зависимости контейнера закреплены в `requirements.lock`. Платформенный ZIP использует отдельный `requirements.txt` по регламенту.

## Локальная проверка

Из корня репозитория запустите приложение.

```sh
docker compose up --build
```

- [Чат](http://127.0.0.1:8080/) запускается с синтетическим сценарием. Для него достаточно чистого клона и Docker.
- [Проверка готовности](http://127.0.0.1:8080/health) возвращает `{"status":"ok"}`, когда веб читает SQLite. Для проверки готовности запрос к модели не нужен.
- SQLite и её схема создаются при запуске. Диалоги и заявки сохраняются в именованном томе `energytool-data`. `docker compose down` останавливает приложение с сохранением тома.
- `APP_PORT` в `.env` меняет порт на компьютере. По умолчанию это `8080`, привязанный к `127.0.0.1`. Внутри контейнера приложение слушает `8080`.

## Проверка с выданной базой

Скопируйте `.env.example` в `.env` и заполните адрес, служебный ключ и имя модели организаторов. Адрес должен быть доступен из контейнера. Для тестового прокси на Mac с Docker Desktop используйте `host.docker.internal`.

Подключите выданный архив как файл только для чтения. Укажите абсолютный путь к нему на компьютере. В примере реальный режим открыт на отдельном локальном порту `8081`.

```sh
docker compose run --rm -p 127.0.0.1:8081:8080 \
  -e ENERGYTOOL_KB_PATH=/input/knowledge-base.zip \
  -v "/absolute/path/knowledge-base.zip:/input/knowledge-base.zip:ro" web
```

Откройте [локальный чат с базой](http://127.0.0.1:8081/). Архив читается при запуске, а вызовы модели идут через настроенный прокси. Для отдельного хранилища тестовых заявок добавьте к команде Compose `-p` с новым именем проекта перед `run`.

## Сборка ZIP внутри контейнера

Эти команды собирают архив в запущенном сервисе `web` и копируют его в текущий каталог.

```sh
docker compose exec -T web python -B scripts/build_submission.py \
  --output /tmp/energytool-submission.zip
docker compose cp web:/tmp/energytool-submission.zip ./energytool-submission.zip
```

GitHub Actions запускает тесты на синтетических данных и локальном прокси, проверяет распакованный ZIP на демо-входе и поднимает веб-сервис через Compose. Команды и проверка платформенного режима описаны отдельно. [Платформенный запуск](I3_SUBMISSION.md)
