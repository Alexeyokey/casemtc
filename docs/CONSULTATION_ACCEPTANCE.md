# Приёмка консультации C2–C5

Веб-чат с RAG и `solution.py` вызывают общий `RagConsultant`. Он строит поисковый запрос из текущей реплики, активной темы и актуальных сведений клиента. При возврате к теме восстанавливаются её собственные реплики и факты. Для нового диалога история начинается с пустого контекста.

Модель получает отобранные фрагменты и возвращает текст, действие, идентификаторы использованных фрагментов и внутренние цитаты. Ядро сопоставляет цитаты с фрагментами, сверяет числа, единицы, диапазоны и обнаруженные оговорки. Коммерческие утверждения требуют прямого подтверждения. При недостаточном основании бот предлагает уточнить условия со специалистом. Известные попытки подменить инструкции отсекаются до генерации. В веб-отладке видны использованные документы и время поиска, генерации и проверки.

| Сценарий | Критерий |
|---|---|
| Учёт арендаторов и короткое «А по фото можно?» | Сохраняется контекст объекта. Ответ учитывает совместимость счётчиков и необходимость сверки. |
| Смена темы на поиск потерь | Поиск и ответ опираются на требования к архиву. Сведения об арендаторах остаются у предыдущей темы. |
| Исправление формата архива | Учитывается отсутствие дневной и ночной разбивки. Следующий вопрос касается почасовых данных или восстановления разбивки. |
| Возврат к учёту и исправление 20 на 12 счётчиков | В поисковом запросе и состоянии актуально 12. Утверждения прежнего ассистента не становятся сведениями клиента. |
| Неподтверждённая стоимость или допуск на ОРЭМ по мощности | Ответ направляет к специалисту. В отладке нет источников, помеченных использованными для отклонённого утверждения. |
| Неверная единица, усечённая оговорка или выдуманная цитата | Ответ заменяется эскалацией. Подтверждённый порог сохраняет единицу и условие применения. |
| Запрос внутренних инструкций и недоверенный фрагмент БЗ | Запрос получает ответ в границах компетенции. Помеченный фрагмент не попадает в данные для модели. |
| Отказ от контактов, запрос обратной связи, исправление и сохранение заявки | Консультация продолжается после отказа. Сохранение требует подтверждения актуального предложения. |
| Новая веб-сессия или отдельная строка CSV | Короткая реплика без собственной истории приводит к уточнению. |

Офлайн-проверки через HTTP API веб-чата и реальный запуск функции обработки `solution.py`:

```sh
python -m pytest -q tests/test_consultation_regressions.py tests/test_integration_acceptance.py tests/test_shared_rag_web.py
```

Тесты используют синтетический ZIP и заданные ответы тестового прокси. На выданной БЗ и модели отдельно оцениваются полнота поиска, применимость рекомендации, смысловая поддержка перефразированных утверждений и обработка противоречий. Для этой проверки прогоняют те же типы сценариев и сопоставляют каждое существенное утверждение с разделом БЗ.
